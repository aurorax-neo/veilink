# Veilink 控制台设计约定

任务：让管理员安全配置 TCP 穿透，并清晰区分节点心跳、期望配置、实际应用结果。首版无流量指标，不暗示服务可达。

- 颜色：navy #14262d 导航，canvas #f4f6f5 工作区，surface #fff，text #1b3038，muted #64767b，teal #087f73 主操作，danger #b83939，warning #956112。
- 字体：系统中文无衬线；ID、端口、版本使用系统 monospace。正文 14px，页标题 28px。
- 间距：4/8/12/16/24/32/48px；圆角 8/12px；边框 #dce5e2。
- 动效：按钮即时反馈；内容进入 180ms ease-out；尊重 reduced-motion，无常驻装饰动画。
- Do：真实 API 数据、操作确认、一次性令牌、清晰空态/错误/加载态、表单标签、可见焦点、窄屏纵向布局。
- Don't：虚构指标、把在线等同可达、输出 HTML 形式的 API 字符串、持久化凭据、隐藏布局溢出。

假设：单管理员，中文界面；同源 cookie 会话。无后台时只显示登录及连接错误，不注入演示运行数据。具体 API 以控制面共享契约为准。
